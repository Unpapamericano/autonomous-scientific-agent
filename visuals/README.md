# Scientific visuals

This folder contains polished, presentation-ready visuals for the project and the recommended research methods.

## Files

- `method_ranking.png` — comparison of scientific methods by practical value
- `workflow_overview.png` — visual workflow of the scientific platform
- `domain_fit_heatmap.png` — method-to-domain fit analysis
- `scientific_summary_report.pdf` — professional multi-page PDF summary for review and reporting
- `portfolio_slide_deck.pdf` — slide-style portfolio deck version for presentations and interviews
- `portfolio_banner.png` — portfolio landing banner / hero graphic

## Trend-driven design workflow

The branding assets are not static. The generator selects a current design palette and writing style based on a small, data-driven trend model so the project stays aligned with modern AI/portfolio conventions without losing clarity or trust.

- modern dark backgrounds with high-contrast text
- blue/green accents for trust and clarity
- friendly but professional writing style
- consistent visual hierarchy across banners, decks, and research summaries

## Regenerate

```bash
python scripts/generate_scientific_visuals.py
```
