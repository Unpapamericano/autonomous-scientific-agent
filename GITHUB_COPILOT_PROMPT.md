## WHAT TO ASK COPILOT FOR

Use these prompts in GitHub Copilot:

### 1. Account Setup
```
How do I create a GitHub account with username Unpapamericano 
and generate a Personal Access Token with repo and read:user scopes?
```

### 2. Repository Creation
```
Guide me through creating an empty public GitHub repository named 
autonomous-scientific-agent without initializing README, license, or gitignore.
```

### 3. Push Commands
```
I need to push my local Git repository to GitHub using PowerShell on Windows.
My local path is C:\Users\49174\projects\autonomous-scientific-agent
My GitHub username is Unpapamericano
My repository is autonomous-scientific-agent
Give me the exact commands to run.
```

### 4. Troubleshooting
```
I got an error when running git push. The error is: [PASTE YOUR ERROR]
How do I fix this?
```

### 5. Verification
```
How do I verify that my code was successfully pushed to GitHub?
What should I see on my GitHub repository page?
```

### 6. Community Sharing
```
I just open-sourced my autonomous research agent project.
It's written in Python with 11 phases, 182 tests, and production-ready.
Where should I share this on the internet to get visibility?
Should I post on HackerNews, Reddit, Twitter? What should I say?
```

## WHAT COPILOT CANNOT DO

❌ Log in to your GitHub account for you
❌ Generate Personal Access Token for you
❌ Run PowerShell commands on your computer
❌ Access your GitHub credentials
❌ Push code without your authentication

**You must do these yourself:**
1. Create GitHub account
2. Generate Personal Access Token (yourself)
3. Create empty repository (on GitHub web)
4. Run PowerShell commands (on your computer)
5. Authenticate when prompted
