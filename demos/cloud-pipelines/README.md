# Cloud pipeline demonstrations

This directory contains demonstration templates for Azure DevOps, GitLab
CI/CD, Terraform, Azure Virtual Networks, Entra ID guidance, and PowerShell
validation.

These files are **not** the active project pipeline. GitHub Actions in
`.github/workflows/` is the supported CI path for this repository. The
templates are intentionally isolated so they can be studied or adapted
without confusing them with production automation.

Terraform examples live in `infra/azure/`. Run them from the repository root
with the commands documented in [`docs/cloud_delivery.md`](../../docs/cloud_delivery.md).
